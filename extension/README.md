# ToolsVerse Browser Extension (Chrome & Edge)

This is a production-ready **Manifest V3** browser extension for ToolsVerse that allows users to instantly access 100+ private in-browser utilities directly from their browser toolbar.

---

## 🚀 How to Test Locally in Chrome / Edge / Brave

1. Open your browser and navigate to:
   - Chrome / Brave: `chrome://extensions/`
   - Microsoft Edge: `edge://extensions/`
2. Enable **Developer mode** (toggle switch in the top-right corner).
3. Click the **"Load unpacked"** button.
4. Select the `toolsverse/extension` folder.
5. The **ToolsVerse** icon will now appear in your browser toolbar! Click it to test the instant search, category filtering, and 1-click tool launch.
